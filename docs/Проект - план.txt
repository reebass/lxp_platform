Спринт 14.1: Интеллектуальный Сайдбар и State Management
Цель: Реализовать контекстно-зависимую боковую панель и двустороннюю синхронизацию данных между холстом (Canvas) и настройками.
Логика работы (UX/UI):
1.	Дефолтное состояние сайдбара: Заголовок «Елементи курсу». Список доступных нод (Текст, Видео, Аудио, Тест, Симуляция) для Drag & Drop.
2.	Авто-именование: При перетаскивании ноды на холст, система проверяет количество нод этого типа и автоматически назначает имя (например, если это второй текст, нода получает label "Текст 2").
3.	Режим редактирования (Context Switch): - При клике на ноду на холсте сайдбар мгновенно переключается.
o	Заголовок сайдбара меняется на «Налаштування: [Имя Ноды]».
o	Появляется кнопка «Назад» (возврат к списку элементов).
4.	Синхронизация имени: В самом верху настроек находится Input с текущим именем ноды ("Текст 2"). При вводе текста в этот Input, имя ноды на самом холсте (Canvas) должно обновляться в реальном времени (Two-way binding).
5.	Сохранение: Кнопка «Зберегти» внутри сайдбара сохраняет локальный стейт конкретной ноды в общий массив данных курса.

o	Нода 1 (Start) -> 연결 -> Нода 2 (Текст: Введение, уже написанное ИИ) -> 연결 -> Нода 3 (Видео: Заглушка "Вставьте видео об эвакуации") -> 연결 -> Нода 4 (Тест: 3 готовых вопроса) -> 연결 -> Нода 5 (Finish).
4.	Админ просто кликает по сгенерированным нодам и точечно их дорабатывает в сайдбаре.

•	Що тестуємо: Заходимо як HR NOVUS, бачимо ваш курс "Основи комунікації", тиснемо "Додати в компанію", переходимо в конструктор і переконуємося, що ми можемо змінити там текст під свої потреби (не ламаючи ваш оригінал).
